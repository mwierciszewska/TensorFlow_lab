# TensorFlow Lab – Deep Learning & NLP Projects

Repozytorium zawiera projekty z zakresu Deep Learning i NLP zrealizowane w TensorFlow.
Celem było praktyczne poznanie architektury modeli, pracy z danymi oraz oceny jakości modeli.

## Projekty

### 🍔 Food Vision – Image Classification (CNN, Transfer Learning)
- Klasyfikacja obrazów jedzenia z wykorzystaniem sieci konwolucyjnych
- Transfer learning (MobileNetV2)
- Dataset: Food images
- Metryki: accuracy, loss
- Projekt skupiony na praktycznym zastosowaniu CNN

### 🧠 NLP – Medical Paper Abstracts
- Analiza i klasyfikacja abstraktów publikacji medycznych
- Przetwarzanie tekstu i modele NLP w TensorFlow
- Praca z danymi tekstowymi i embeddingami

## Technologie
- Python
- TensorFlow / Keras
- NumPy, Pandas, Matplotlib
- Jupyter Notebook
